# Changelog

## v0.0 — Initial Release

- First playable public build of Shadow Knight.
- Core movement and camera.
- Player HP, XP, levels, Gold and damage progression.
- Goblin, Orc and Demon enemies.
- Shadow Lord boss with Phase 2 and projectiles.
- Combat, enemy AI and death/reward loop.
- Inventory and equipment.
- Health Potion, weapons, armor and boots.
- Item drops.
- Elder NPC and Goblin Hunt quest.
- Shop.
- Save / Load with browser `localStorage`.
- Automatic save every 30 seconds.
- Save on page exit/refresh.
- GitHub Pages deployment workflow.

### Release policy

v0.0 is the frozen initial release. Future gameplay changes belong to later versions and are not part of v0.0.
